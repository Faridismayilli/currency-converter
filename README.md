# Currency Converter

A simple **Currency Converter** built with **React** using **Vite**.  
It fetches exchange rates from a free API and allows converting between multiple currencies.

## Features

- Convert currencies using a free API
- Select from/to currencies dynamically
- Switch between base and target currencies

## Tech Stack

- React
- Vite
- Axios
- React Icons
